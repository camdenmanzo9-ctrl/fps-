# Virtual Hand (Fabric, client-side, Minecraft 26.1.2)

- Z / X: target Item A / Item B name. Backspace: clear hand. G: 50-50 Matrix Hub.
- Hub: link the crosshair block, import Item A / B from main hand.
- Toggling a lever ON next to the linked block adds the current target to the hand once per flick.

Build: `gradle build` (JDK 25). To add a wrapper: `gradle wrapper`.
