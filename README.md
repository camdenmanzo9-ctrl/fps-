# Virtual Hand (Fabric, client-side, Minecraft 26.1.2)

- Z / X: target Item A / Item B name. Backspace: clear hand. G: config screen.
- Config screen: link crosshair block, set Item A / B from main hand.
- Toggling a lever ON next to the linked block adds the current target to the hand.

Build: `gradle build` (JDK 25). To add a wrapper: `gradle wrapper`.
